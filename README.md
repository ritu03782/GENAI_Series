# Generative AI Series 🤖

A hands-on learning repository for exploring **Generative AI, LangChain, LLMs, RAG, Prompt Engineering, and AI-powered applications**.

This repository contains the concepts, experiments, notebooks, and small applications I build while learning and practicing Generative AI.

---

## 🎯 Goals

- Understand the fundamentals of Generative AI and LLMs
- Learn how LLM applications are built
- Practice LangChain and its core components
- Work with different LLM providers and local models
- Learn prompt engineering
- Build RAG-based applications
- Explore AI agents and tool calling
- Build practical GenAI applications using Streamlit

---

## 🛠️ Tech Stack

- **Python**
- **LangChain**
- **Streamlit**
- **Google Gemini**
- **Ollama**
- **Qwen**
- **Prompt Engineering**
- **RAG**
- **Vector Databases**
- **LLM APIs**
